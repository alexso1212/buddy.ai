# task-09: 企业智能初始化（前端 Onboarding 改造）

> **前置条件**：task-08 完成（后端 /api/setup/analyze 和 /api/setup/confirm 可用）
> **预计耗时**：2-3 天
> **新增文件**：`client/src/pages/smart-setup.tsx`（或改造现有 OnboardingPage）
> **改动文件**：`client/src/App.tsx`（路由调整）、可能改 `OnboardingPage.tsx`
> **风险等级**：低（主要是新增页面，现有页面改动小）

-----

## 目标

新用户注册后（或已有 owner 主动触发），看到一个”企业智能初始化”流程：上传文件包 → AI分析进度 → 确认/编辑结果 → 一键完成设置。

-----

## 设计原则

1. **和现有 Onboarding 共存**——不删除现有的 OnboardingPage，而是在其中增加”智能初始化”入口，或者作为独立页面
1. **可跳过**——用户可以选择跳过智能初始化，走手动设置
1. **可重复触发**——已设置过的组织也可以从设置页面再次上传文件补充
1. **遵循现有代码风格**——shadcn/ui、TanStack Query、wouter、Tailwind

-----

```typescript
// 文件选择（支持 ZIP 和多文件）
const fileInputRef = useRef<HTMLInputElement>(null);
const [selectedFiles, setSelectedFiles] = useState<File[]>([]);

// 拖拽区域
function handleDrop(e: React.DragEvent) {
  e.preventDefault();
  const files = Array.from(e.dataTransfer.files);
  setSelectedFiles(prev => [...prev, ...files]);
}

// 上传并触发分析
const analyzeMutation = useMutation({
  mutationFn: async (files: File[]) => {
    const formData = new FormData();
    files.forEach(file => formData.append('files', file));

    const res = await fetch('/api/setup/analyze', {
      method: 'POST',
      headers: { 'Authorization': `Bearer ${token}` },
      body: formData,
    });
    if (!res.ok) {
      const err = await res.json();
      throw new Error(err.error || '分析失败');
    }
    return res.json();
  },
  onSuccess: (data) => {
    setProfile(data.data.profile);
    setCacheKey(data.data.cacheKey);
    setFileCount(data.data.fileCount);
    setStep('confirm'); // 跳过 analyzing 中间态（如果请求够快）
  },
  onError: (err: Error) => {
    toast({ title: '分析失败', description: err.message, variant: 'destructive' });
    setStep('upload');
  },
});

function handleStartAnalysis() {
  if (selectedFiles.length === 0) return;
  setStep('analyzing');
  analyzeMutation.mutate(selectedFiles);
}
```

**关键实现**：profile 状态是可编辑的。每个编辑操作都更新 `profile` state：

```typescript
// 编辑公司名称
function updateCompanyName(name: string) {
  setProfile(prev => prev ? { ...prev, companyName: name } : prev);
}

// 删除部门
function removeDepartment(index: number) {
  setProfile(prev => {
    if (!prev) return prev;
    const newDepts = [...prev.departments];
    newDepts.splice(index, 1);
    return { ...prev, departments: newDepts };
  });
}

// 添加部门
function addDepartment() {
  setProfile(prev => {
    if (!prev) return prev;
    return {
      ...prev,
      departments: [...prev.departments, { name: '新部门', description: '', children: [] }]
    };
  });
}

// 编辑部门名称
function updateDepartmentName(index: number, name: string) {
  setProfile(prev => {
    if (!prev) return prev;
    const newDepts = [...prev.departments];
    newDepts[index] = { ...newDepts[index], name };
    return { ...prev, departments: newDepts };
  });
}
```

## STEP 3：处理二次初始化

如果用户已经设置过（已有部门和知识库），再次上传文件应该是**追加**而不是**覆盖**。

在 Step 3 确认页面顶部显示提醒：

```typescript
// 获取当前设置状态
const { data: setupStatus } = useQuery({
  queryKey: ['/api/setup/status'],
  queryFn: async () => {
    const res = await fetch('/api/setup/status', {
      headers: { 'Authorization': `Bearer ${token}` },
    });
    return (await res.json()).data;
  },
});

// 如果已有数据，显示提醒
{setupStatus?.isSetupComplete && (
  <div className="rounded-lg border p-3 text-sm text-muted-foreground mb-4">
    ℹ️ 你的组织已有 {setupStatus.departmentCount} 个部门和 {setupStatus.kbDocumentCount} 份知识库文档。
    本次操作将<strong>新增</strong>以下内容，不会覆盖已有设置。
  </div>
)}
```

后端 `confirmAndSetup` 已经是追加模式（createDepartment / createJobRole 不会删除已有的），所以不需要额外处理。但如果AI识别出的部门名和已有部门重名，会创建重复部门。后端可以加去重逻辑，也可以在前端确认页面提示”销售部 已存在，将跳过”。

**简单方案（第一版）**：不做去重，让用户在确认页面手动删除重复的。
**增强方案（后续）**：后端检查同名部门/岗位，自动标记并让用户选择”跳过”还是”新建”。
