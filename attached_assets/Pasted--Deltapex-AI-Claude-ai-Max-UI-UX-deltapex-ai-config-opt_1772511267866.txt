## 一、Extended Thinking 折叠交互

Claude.ai 的 thinking 展示有一套完整的 UI 状态机：

### 1.1 状态流转

```
用户发送消息
  → [思考中] 显示脉动动画 + "Thinking..."（实时更新已思考秒数）
  → [思考完成] 折叠为一行摘要，如 "Thought for 12 seconds"
  → [回复开始] 流式输出正式回复内容
```

### 1.2 UI 组件设计

```tsx
interface ThinkingBlockProps {
  status: 'thinking' | 'complete'
  thinkingContent: string      // 思考的完整文本
  durationSeconds: number      // 思考耗时
  isExpanded: boolean          // 是否展开
}

// 折叠状态（默认）：
// ┌──────────────────────────────────────┐
// │ 💭 Thought for 12 seconds        ▶  │
// └──────────────────────────────────────┘

// 展开状态（用户点击后）：
// ┌──────────────────────────────────────┐
// │ 💭 Thought for 12 seconds        ▼  │
// ├──────────────────────────────────────┤
// │ 让我分析一下这个问题...              │
// │ 首先考虑几个方面：                    │
// │ 1. 数据结构的选择...                 │
// │ ...                                  │
// └──────────────────────────────────────┘
```

### 1.3 关键细节

- **思考中阶段**：显示脉动/呼吸动画 + 实时计时（“Thinking…” → “Thinking for 3s” → “Thinking for 8s”）
- **思考完成后**：自动折叠为一行，显示总耗时（“Thought for 12 seconds”）
- **用户可点击展开/收起**思考过程的完整文本
- **思考内容用浅色/灰色文字**渲染，与正式回复在视觉上明确区分
- **如果 thinking 未启用**，则完全不显示这个区块

### 1.4 流式处理时序

```typescript
// 流式事件处理
function handleStreamEvent(event: StreamEvent) {
  switch (event.type) {
    case 'message_start':
      // 初始化消息容器
      showTypingIndicator()
      break

    case 'content_block_start':
      if (event.content_block.type === 'thinking') {
        // 进入思考阶段
        startThinkingTimer()
        showThinkingAnimation()  // 脉动动画
      } else if (event.content_block.type === 'text') {
        // 进入正式回复阶段
        stopThinkingTimer()
        collapseThinkingBlock()  // 自动折叠思考内容
      }
      break

    case 'content_block_delta':
      if (event.delta.type === 'thinking_delta') {
        // 追加到思考缓冲区（用户展开时可见）
        appendThinkingText(event.delta.thinking)
      } else if (event.delta.type === 'text_delta') {
        // 实时渲染到回复区域
        appendResponseText(event.delta.text)
      }
      break

    case 'content_block_stop':
      // 当前 block 结束
      break

    case 'message_stop':
      // 消息完成，显示操作按钮（复制、重试等）
      showMessageActions()
      break
  }
}
```

## 二、工具调用 / 动作的折叠展示

Claude.ai 在执行搜索、代码运行、文件操作等”动作”时，会以折叠卡片的形式展示。

### 2.1 动作类型与展示

```
┌─ 🔍 Searched the web                         ▶ ─┐
└──────────────────────────────────────────────────┘

┌─ 📄 Read file: schema.ts                     ▶ ─┐
└──────────────────────────────────────────────────┘

┌─ 💻 Executed code                             ▶ ─┐
└──────────────────────────────────────────────────┘

┌─ 🧮 Used calculator                          ▶ ─┐
└──────────────────────────────────────────────────┘
```

### 2.2 折叠卡片组件

```tsx
interface ActionCardProps {
  type: 'web_search' | 'code_execution' | 'file_read' | 'tool_use'
  label: string              // 如 "Searched the web for: Claude API pricing"
  status: 'running' | 'complete' | 'error'
  detail: string             // 展开后显示的详细内容
  isExpanded: boolean
}

// 运行中状态：
// ┌──────────────────────────────────────┐
// │ 🔍 Searching the web...          ⟳  │  ← 旋转加载动画
// └──────────────────────────────────────┘

// 完成状态（默认折叠）：
// ┌──────────────────────────────────────┐
// │ 🔍 Searched 3 sites              ▶  │
// └──────────────────────────────────────┘

// 展开状态：
// ┌──────────────────────────────────────┐
// │ 🔍 Searched 3 sites              ▼  │
// ├──────────────────────────────────────┤
// │ • anthropic.com/pricing             │
// │ • docs.anthropic.com/api            │
// │ • community.anthropic.com           │
// └──────────────────────────────────────┘

// 错误状态：
// ┌──────────────────────────────────────┐
// │ ⚠️ Search failed — Retry          ▶  │  ← 红/橙色调
// └──────────────────────────────────────┘
```

### 2.3 动作卡片在消息流中的位置

动作卡片出现在 AI 回复内容的**上方或中间**，按执行顺序排列：

```
┌─────────── AI 回复 ───────────┐
│                                │
│ 💭 Thought for 5 seconds   ▶  │  ← 思考折叠
│                                │
│ 🔍 Searched 2 sites        ▶  │  ← 动作折叠
│ 📄 Read: pricing page      ▶  │  ← 动作折叠
│                                │
│ 根据最新的定价信息，           │  ← 正式回复内容
│ Claude API 的价格是...         │
│                                │
│ [复制] [重试] [👍] [👎]       │  ← 操作按钮
└────────────────────────────────┘
```

const markdownRenderConfig = {

### 3.2 代码块特殊交互

Claude.ai 的代码块不仅仅是高亮，还有交互：

```
┌─ typescript ──────────────── [Copy] ─┐
│ function hello() {                    │
│   console.log("Hello, world!")        │
│ }                                     │
└───────────────────────────────────────┘
```

对于较长的代码块（如完整文件），Claude.ai 会渲染为”Artifact”卡片：

```
┌──────────────────────────────────────┐
│ 📄 model-router.ts                   │
│ TypeScript · 85 lines                │
│                              [Open]  │
└──────────────────────────────────────┘
```

### 3.3 长回复的渐进式渲染

```typescript
// 流式输出时的渲染策略
const renderConfig = {
  // 逐字符渲染（打字机效果）
  // Claude.ai 实际上是逐 token 渲染，不是逐字符
  renderMode: 'token',

  // Markdown 实时解析
  // 在流式过程中就开始解析 markdown，不等完成
  incrementalMarkdown: true,

  // 代码块在关闭 ``` 之前显示为纯文本
  // 关闭后立刻应用语法高亮
  deferCodeHighlight: true,

  // 滚动行为：新内容出现时自动滚动到底部
  // 但如果用户主动上滚阅读，则停止自动滚动
  autoScroll: {
    enabled: true,
    pauseOnUserScroll: true,      // 用户上滚时暂停
    resumeThreshold: 50,          // 距底部 50px 以内时恢复
  }
}
```

### 4.2 模型选择器

Claude.ai Max 允许用户在输入框下方切换模型：

```
┌─────────────────────────────────────────────┐
│  输入消息...                                 │
│                                              │
├──────────────────────────────────────────────┤
│ 🧠 Sonnet 4.6 ▼  │ 💡Extended Thinking ○/●  │
└──────────────────────────────────────────────┘

下拉选项：
┌──────────────────────┐
│ ⚡ Haiku 4.5          │  ← 最快
│ 🧠 Sonnet 4.6    ✓   │  ← 默认，推荐
│ 🔬 Opus 4.6          │  ← 最强，较慢
└──────────────────────┘
```

- **默认选中 Sonnet**（和 Claude.ai 一致）
- Extended Thinking 作为独立开关，用户可手动启用/关闭
- 切换模型不清除对话历史

## 五、消息操作按钮

### 5.1 AI 消息底部操作

每条 AI 回复底部有一排操作按钮（hover 时显示或始终显示）：

```
回复内容...

[📋 Copy] [🔄 Retry] [👍] [👎]
```

```typescript
const messageActions = {
  // 复制：复制纯文本或 Markdown 到剪贴板
  copy: {
    format: 'markdown',          // 复制 markdown 源码，不是渲染后的 HTML
    showToast: true,             // 显示 "已复制" 提示
  },

  // 重试：重新生成当前回复
  retry: {
    // 重新发送最后一条用户消息
    // 新回复替换当前回复（可切换查看不同版本）
    keepPreviousVersions: true,  // 保留历史版本，可左右翻页
  },

  // 反馈
  thumbsUp: { /* 正反馈 */ },
  thumbsDown: {
    // 展开反馈表单
    showFeedbackForm: true,
    feedbackOptions: [
      '回答不准确',
      '没有理解我的问题',
      '回复太长/太短',
      '格式有问题',
      '其他'
    ]
  },

  // 编辑用户消息
  editUserMessage: {
    enabled: true,               // 用户可以编辑已发送的消息
    // 编辑后从该消息重新生成后续所有回复
    regenerateFromEdit: true,
  }
}
```

### 5.2 回复版本切换

当用户点击”重试”或编辑消息后，支持在不同版本间切换：

```
          ◀  2 / 3  ▶              ← 版本切换器
┌──────────────────────────────┐
│ 这是第 2 次生成的回复...       │
└──────────────────────────────┘

## 七、错误处理与状态展示

### 7.1 错误类型与 UI 反馈

```typescript
const errorHandling = {
  // 网络错误
  networkError: {
    display: 'inline',           // 在消息区域内显示
    message: '网络连接中断，请检查网络后重试',
    showRetryButton: true,
    autoRetry: {
      enabled: true,
      maxAttempts: 3,
      backoffMs: [1000, 3000, 5000],
    }
  },

  // API 限流 (429)
  rateLimitError: {
    display: 'inline',
    message: '请求过于频繁，请稍后再试',
    showRetryButton: true,
    showCooldownTimer: true,     // 显示倒计时
    // Claude.ai 显示: "You've hit the usage limit. Try again in X minutes."
  },

  // 上下文过长 (413 / context_length_exceeded)
  contextTooLong: {
    display: 'modal',            // 弹窗提示
    message: '对话过长，建议开始新对话或等待系统自动裁剪历史',
    actions: ['开始新对话', '自动裁剪后重试'],
    onAutoTrim: () => {
      // 自动裁剪最早的消息，保留最近 10 轮
      trimOldestMessages(10)
      retryLastMessage()
    }
  },

  // 模型服务不可用 (503)
  serviceUnavailable: {
    display: 'inline',
    message: '服务暂时不可用，正在自动切换备用模型...',
    // 自动 fallback 到备用模型
    fallbackChain: ['claude-sonnet-4-6', 'gpt-4o', 'deepseek-chat'],
    notifyUser: true,            // 告知用户已切换模型
  },

  // 内容审核拒绝
  contentFiltered: {
    display: 'inline',
    message: '该请求无法处理，请调整内容后重试',
    showRetryButton: false,
  },

  // 流式中断（生成到一半断了）
  streamInterrupted: {
    display: 'inline',
    preservePartialContent: true,  // 保留已生成的部分
    message: '回复生成中断',
    showRetryButton: true,         // "继续生成" 按钮
    onRetry: 'continue',           // 从断点续传而非重新生成
  }
}
```
