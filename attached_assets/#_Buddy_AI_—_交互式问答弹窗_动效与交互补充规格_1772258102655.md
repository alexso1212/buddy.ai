## 二、触摸光照效果（Touch Spotlight）  
  
### 效果描述  
  
当手指触碰弹窗（或输入框）的任意位置时，在触摸点产生一个**白色径向渐变光斑**，像手电筒从背面照在毛玻璃上的效果。这不是 Material Design 的 ripple（波纹扩散），而是一个**静态跟手的光照区域**。  
  
### 行为规则  
  
- **触摸开始**：在手指触点位置，立即出现白色径向渐变光斑  
- **手指移动**：光斑跟随手指位置实时更新  
- **手指抬起**：光斑以约 300ms 淡出消失  
- **长按**：光斑持续显示，不会自动消失  
  
### 实现方式  
  
```css  
/* 容器需要 position: relative 和 overflow: hidden */  
.touch-spotlight-container {  
  position: relative;  
  overflow: hidden;  
}  
  
/* 光斑层 — 用伪元素或单独 div */  
.touch-spotlight {  
  position: absolute;  
  width: 300px;  
  height: 300px;  
  border-radius: 50%;  
  /* 关键：白色径向渐变，中心较亮，边缘完全透明 */  
  background: radial-gradient(  
    circle at center,  
    rgba(255, 255, 255, 0.12) 0%,  
    rgba(255, 255, 255, 0.05) 40%,  
    rgba(255, 255, 255, 0) 70%  
  );  
  pointer-events: none;  /* 不干扰点击事件 */  
  transform: translate(-50%, -50%);  /* 以手指位置为中心 */  
  transition: opacity 300ms ease-out;  
}  
  
.touch-spotlight.hidden {  
  opacity: 0;  
}  
```  
  
### React 实现参考  
  
```tsx  
function TouchSpotlight({ children, className }: { children: React.ReactNode; className?: string }) {  
  const [spotPos, setSpotPos] = useState<{ x: number; y: number } | null>(null);  
  const containerRef = useRef<HTMLDivElement>(null);  
  
  const handleTouchStart = (e: React.TouchEvent) => {  
    const rect = containerRef.current?.getBoundingClientRect();  
    if (!rect) return;  
    const touch = e.touches[0];  
    setSpotPos({  
      x: touch.clientX - rect.left,  
      y: touch.clientY - rect.top,  
    });  
  };  
  
  const handleTouchMove = (e: React.TouchEvent) => {  
    const rect = containerRef.current?.getBoundingClientRect();  
    if (!rect) return;  
    const touch = e.touches[0];  
    setSpotPos({  
      x: touch.clientX - rect.left,  
      y: touch.clientY - rect.top,  
    });  
  };  
  
  const handleTouchEnd = () => {  
    // 延迟清除，让淡出动画播放  
    setTimeout(() => setSpotPos(null), 300);  
  };  
  
  return (  
    <div  
      ref={containerRef}  
      className={`touch-spotlight-container ${className}`}  
      onTouchStart={handleTouchStart}  
      onTouchMove={handleTouchMove}  
      onTouchEnd={handleTouchEnd}  
    >  
      {children}  
      {spotPos && (  
        <div  
          className="touch-spotlight"  
          style={{ left: spotPos.x, top: spotPos.y }}  
        />  
      )}  
    </div>  
  );  
}  
```  
  
### 应用范围  
  
这个触摸光照效果应用于以下所有可交互的暗色容器：  
  
- 聊天输入框（Reply to Claude）  
- 问题弹窗卡片  
- 选项行（点击选项时也会有）

## 三、卡片滑动切换动效  
  
### 效果描述  
  
当有多个问题时（如 “1 of 3”），用户通过**水平滑动手势**在问题之间切换。整个过程像把一张实体卡片往左推走，露出下面的另一张卡片。  
  
### 完整动画序列  
  
```  
状态1：正常展示第1题  
  → 卡片居中，scale(1.0)，正常清晰  
  
状态2：手指按住 + 开始左滑  
  → 当前卡片跟随手指向左移动（translateX 跟手）  
  → 同时逐渐缩小（scale 从 1.0 → 0.92 左右）  
  → 下一张卡片在右侧就位，准备滑入  
  
状态3：手指继续滑 / 超过阈值后释放  
  → 当前卡片加速滑出左侧 + 继续缩小  
  → 下一张卡片从右侧滑入到居中位置  
  → 分页指示器更新（1 of 3 → 2 of 3）  
  
状态4：新卡片到位  
  → 新卡片居中，scale(1.0)，正常清晰  
```  
  
### 关键参数  
  
```typescript  
const SWIPE_CONFIG = {  
  // 手势触发阈值：滑动超过卡片宽度的 30% 就触发切换  
  swipeThreshold: 0.3,  
  
  // 当前卡片滑出时的缩放比例  
  exitScale: 0.92,  
  
  // 过渡动画时长（手指释放后的自动完成动画）  
  transitionDuration: 350,  // ms  
  
  // 缓动函数 — 使用 spring 感觉更自然  
  transitionEasing: 'cubic-bezier(0.25, 0.46, 0.45, 0.94)',  
  // 或使用 framer-motion spring:  
  springConfig: { damping: 28, stiffness: 300 },  
  
  // 滑动时跟手的阻尼系数（0-1，越小越有阻力感）  
  dragElasticity: 0.8,  
};  
```  
  
### framer-motion 实现参考  
  
```tsx  
import { useState } from 'react';  
import { motion, AnimatePresence, PanInfo } from 'framer-motion';  
  
interface QuestionCarouselProps {  
  questions: InteractiveQuestion[];  
  onAnswer: (questionId: string, answer: string[]) => void;  
}  
  
function QuestionCarousel({ questions, onAnswer }: QuestionCarouselProps) {  
  const [currentIndex, setCurrentIndex] = useState(0);  
  const [direction, setDirection] = useState(0);  // -1 左滑, 1 右滑  
  
  const handleDragEnd = (e: any, info: PanInfo) => {  
    const swipeThreshold = 100;  // px  
    if (info.offset.x < -swipeThreshold && currentIndex < questions.length - 1) {  
      setDirection(-1);  
      setCurrentIndex(prev => prev + 1);  
    } else if (info.offset.x > swipeThreshold && currentIndex > 0) {  
      setDirection(1);  
      setCurrentIndex(prev => prev - 1);  
    }  
  };  
  
  // 卡片进出动画变体  
  const cardVariants = {  
    // 从右侧进入  
    enter: (direction: number) => ({  
      x: direction < 0 ? '100%' : '-100%',  
      scale: 0.92,  
      opacity: 0.8,  
    }),  
    // 居中显示  
    center: {  
      x: 0,  
      scale: 1,  
      opacity: 1,  
      transition: {  
        type: 'spring',  
        damping: 28,  
        stiffness: 300,  
      },  
    },  
    // 向左/右滑出  
    exit: (direction: number) => ({  
      x: direction < 0 ? '-100%' : '100%',  
      scale: 0.92,  
      opacity: 0.8,  
      transition: {  
        type: 'spring',  
        damping: 28,  
        stiffness: 300,  
      },  
    }),  
  };  
  
  return (  
    <div className="carousel-container">  
      {/* 分页指示器 */}  
      <div className="pagination">  
        <button  
          onClick={() => { setDirection(1); setCurrentIndex(prev => prev - 1); }}  
          disabled={currentIndex === 0}  
        >  
          &lt;  
        </button>  
        <span>{currentIndex + 1} of {questions.length}</span>  
        <button  
          onClick={() => { setDirection(-1); setCurrentIndex(prev => prev + 1); }}  
          disabled={currentIndex === questions.length - 1}  
        >  
          &gt;  
        </button>  
        <button className="close-btn" onClick={onClose}>×</button>  
      </div>  
  
      {/* 可滑动的问题卡片 */}  
      <AnimatePresence initial={false} custom={direction} mode="popLayout">  
        <motion.div  
          key={currentIndex}  
          custom={direction}  
          variants={cardVariants}  
          initial="enter"  
          animate="center"  
          exit="exit"  
          drag="x"  
          dragConstraints={{ left: 0, right: 0 }}  
          dragElastic={0.8}  
          onDragEnd={handleDragEnd}  
          className="question-card"  
          // 拖拽过程中实时缩放  
          style={{  
            // framer-motion 的 drag 会自动处理 translateX  
            // 用 onDrag 回调实时调整 scale 可增强效果  
          }}  
        >  
          <h3 className="question-title">  
            {questions[currentIndex].question}  
          </h3>  
  
          <div className="options-list">  
            {questions[currentIndex].options.map((option, i) => (  
              <button  
                key={option}  
                className="option-row"  
                onClick={() => handleOptionSelect(option)}  
              >  
                <span className="option-number">{i + 1}</span>  
                <span className="option-text">{option}</span>  
              </button>  
            ))}  
          </div>  
  
          {/* 底部自定义输入 */}  
          <div className="custom-input">  
            <span className="input-icon">✏️</span>  
            <input  
              type="text"  
              placeholder="Type your answer..."  
              onKeyDown={(e) => {  
                if (e.key === 'Enter' && e.currentTarget.value) {  
                  handleCustomAnswer(e.currentTarget.value);  
                }  
              }}  
            />  
          </div>  
        </motion.div>  
      </AnimatePresence>  
    </div>  
  );  
}  
```

## 四、选项选中后自动跳转  
  
### 行为描述  
  
对于单选题，用户**点击选项后不需要按确认按钮**，系统自动延迟一小段时间后切换到下一题。  
  
### 时序  
  
```  
用户点击选项  
  → 0ms:    选项行高亮（selected 状态）  
  → 0ms:    触摸光照效果闪现  
  → 400ms:  开始卡片滑动切换动画  
  → 750ms:  下一题卡片到位，可以开始交互  
```  
  
### 最后一题特殊处理  
  
当用户在最后一题（如 3 of 3）选择了选项后：  
  
- 不再滑动到下一题  
- 延迟 400ms 后，整个弹窗卡片向下滑出 + 遮罩淡出  
- 所有选择结果打包发送给 AI

## 七、实现优先级调整  
  
基于本补充文档，建议调整实现顺序：  
  
### Phase 1（最小可用）  
  
1. Bottom Sheet 弹出/收起 + 暗色遮罩  
1. 单题卡片展示（纵向选项列表）  
1. 选项点击 → 结果回传给 AI  
1. 分页指示器（静态，不可滑动）  
  
### Phase 2（核心体验）  
  
1. 多题卡片左右滑动切换（framer-motion drag）  
1. 单选自动跳转下一题  
1. 底部 “Type your answer…” 自定义输入  
1. 关闭按钮功能  
  
### Phase 3（体验打磨）  
  
1. **触摸光照效果（Touch Spotlight）**  
1. 滑动切换时的 scale 缩放效果  
1. 分页指示器左右箭头点击切换  
1. 移动端触摸手势优化（惯性、边界回弹）
