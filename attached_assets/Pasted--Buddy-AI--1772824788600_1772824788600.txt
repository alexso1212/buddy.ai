## 三、XLSX 的特殊价值

Excel文件对 Smart Setup 特别重要——**花名册就是员工信息的最佳来源**：

```
典型的员工花名册.xlsx：

| 工号 | 姓名 | 英文名 | 部门 | 岗位 | 入职日期 | 手机号 | 邮箱 |
|------|------|--------|------|------|----------|--------|------|
| 001 | 张三 | Sam | 销售部 | 销售经理 | 2022-03-15 | 138xxxx | sam@co |
| 002 | 李四 | Lisa | 行政部 | 行政主管 | 2021-06-01 | 139xxxx | lisa@co |
```

这比从合同文件里用AI推测准确100倍。**一个Excel表就能直接建好所有成员档案。**

### XLSX 处理方式

项目已有 SheetJS（`xlsx` 包在 dependencies 里）。处理方式：

```typescript
import * as XLSX from 'xlsx';

function extractTextFromXlsx(filePath: string): string {
  const workbook = XLSX.readFile(filePath);
  const sheets: string[] = [];
  
  for (const sheetName of workbook.SheetNames) {
    const sheet = workbook.Sheets[sheetName];
    // 转为 CSV 格式的纯文本（保留表格结构）
    const csv = XLSX.utils.sheet_to_csv(sheet);
    if (csv.trim().length > 10) {
      sheets.push(`=== 工作表: ${sheetName} ===\n${csv}`);
    }
  }
  
  return sheets.join('\n\n');
}
```

关键：Excel转出来的CSV文本保留了行列结构，AI（特别是Opus）能很好地理解表格数据。

### XLSX 的智能初始化增强

如果AI检测到上传的文件是花名册格式（有”姓名”“部门”“岗位”等列），可以直接结构化解析，不需要AI猜：

```typescript
function detectRosterFormat(csvText: string): boolean {
  const firstLine = csvText.split('\n')[0].toLowerCase();
  const rosterKeywords = ['姓名', '部门', '岗位', '职位', '工号', '入职', 'name', 'department'];
  const matchCount = rosterKeywords.filter(kw => firstLine.includes(kw)).length;
  return matchCount >= 3; // 表头匹配3个以上关键词就判定为花名册
}
```

## 四、图片处理的价值

很多企业的**组织架构图是图片格式**（在PPT里画的、截图保存的、PS做的）。

处理方式：用 Claude Vision（把图片发给AI，让它描述内容）。

```typescript
// 在 extractText.ts 中新增图片处理
case 'jpg':
case 'jpeg':
case 'png': {
  // 读取图片为 base64
  const imageBase64 = fs.readFileSync(absolutePath).toString('base64');
  const mimeType = ext === 'png' ? 'image/png' : 'image/jpeg';
  
  // 发给 Claude Vision 提取文字内容
  const response = await aiClient.chat.completions.create({
    model: 'claude-haiku-4-5-20251001',  // Haiku 就够用
    max_tokens: 2000,
    messages: [{
      role: 'user',
      content: [
        { type: 'image_url', image_url: { url: `data:${mimeType};base64,${imageBase64}` } },
        { type: 'text', text: '请提取这张图片中的所有文字内容。如果是组织架构图，请描述其层级结构。如果是表格，请用文字还原表格内容。' }
      ]
    }]
  });
  
  return response.choices[0]?.message?.content || '';
}
```

成本：Haiku处理一张图片约 ¥0.01-0.03，可接受。

**但第一版可以不做图片**——先把文档类格式全覆盖。图片OCR作为增强功能，后续加。

## 五、实现建议

### 立即做（和 task-16 一起）

修改 `server/services/kb/extractText.ts`，新增格式支持：

```typescript
export async function extractText(filePath: string, fileType: string): Promise<string> {
  switch (fileType.toLowerCase()) {
    case 'pdf': { /* 已有 */ }
    case 'docx': { /* 已有 */ }
    case 'doc': { /* mammoth 也支持 .doc */ return mammoth... }
    case 'txt': case 'md': { /* 已有 */ }
    
    // ====== 新增 ======
    case 'xlsx': case 'xls': {
      const XLSX = await import('xlsx');
      const workbook = XLSX.readFile(filePath);
      const sheets: string[] = [];
      for (const name of workbook.SheetNames) {
        const csv = XLSX.utils.sheet_to_csv(workbook.Sheets[name]);
        if (csv.trim().length > 10) sheets.push(`=== ${name} ===\n${csv}`);
      }
      return sheets.join('\n\n');
    }
    
    case 'csv': {
      return fs.readFileSync(filePath, 'utf-8');
    }
    
    case 'pptx': {
      // 需要安装 pptx 解析库，或用简单的 XML 提取
      // 方案A：安装 officegen 或 pptx-parser
      // 方案B：用 adm-zip 解压 pptx（它本质是zip），读取里面的 XML 文件提取文本
      const AdmZip = (await import('adm-zip')).default;
      const zip = new AdmZip(filePath);
      const texts: string[] = [];
      const entries = zip.getEntries();
      for (const entry of entries) {
        if (entry.entryName.startsWith('ppt/slides/slide') && entry.entryName.endsWith('.xml')) {
          const xml = entry.getData().toString('utf-8');
          // 用正则提取 <a:t> 标签中的文本
          const matches = xml.match(/<a:t>(.*?)<\/a:t>/g) || [];
          const slideText = matches.map(m => m.replace(/<\/?a:t>/g, '')).join(' ');
          if (slideText.trim()) texts.push(slideText);
        }
      }
      return texts.join('\n\n');
    }
    
    case 'html': case 'htm': {
      const cheerio = await import('cheerio');
      const html = fs.readFileSync(filePath, 'utf-8');
      const $ = cheerio.load(html);
      $('script, style, nav, header, footer').remove();
      return $('body').text().trim();
    }
    
    case 'rtf': {
      // 简单处理：去掉 RTF 控制符
      const rtf = fs.readFileSync(filePath, 'utf-8');
      return rtf.replace(/\{\\[^{}]*\}/g, '').replace(/\\[a-z]+\d* ?/gi, '').replace(/[{}]/g, '').trim();
    }
    
    case 'json': {
      const json = fs.readFileSync(filePath, 'utf-8');
      return json; // 原样返回，AI能读懂JSON
    }

    default:
      throw new Error(`不支持的文件类型: ${fileType}`);
  }
}
```

## 六、花名册特殊处理建议（可选增强）

如果 Haiku 在阶段1检测到文件是花名册格式（relevanceScore=5 + 包含姓名/部门/岗位列），可以跳过 AI 提取，直接用结构化解析：

```
Haiku 返回：
{
  "relevanceScore": 5,
  "category": "roster",  // 新增类型：花名册
  "summary": "员工花名册，包含20人的姓名、部门、岗位信息",
  ...
}

如果 category === 'roster'：
  → 用 XLSX 库直接解析为结构化数据
  → 自动映射列名到 MemberProfile 字段
  → 不需要 Opus 分析这个文件
```

这个是增强，第一版可以不做。先确保 Excel 文件的文本能被正确提取送给 AI 分析就行。
