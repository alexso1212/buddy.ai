## 目标

在 Agent 聊天页面的输入栏中新增一个「知识库」开关按钮，让用户可以手动开启/关闭知识库检索。交互模式参照现有的「Web 搜索」开关。

-----

## 设计原则

**和 Web 搜索开关保持一致。** 你的 AiInputBar 已经有一个 Web 搜索的开关按钮（Tavily），知识库开关应该和它在视觉风格、交互逻辑、代码结构上完全一致。这样用户学习成本为零。

-----

## STEP 1：找到 Web 搜索开关的代码模式

在 `client/src/components/ai/AiInputBar.tsx`（943 行）中，找到 Web 搜索开关的实现。它大概是这样的模式：

```typescript
// 状态
const [webSearchEnabled, setWebSearchEnabled] = useState(false);

// UI：某个图标按钮，点击切换状态，激活时有高亮样式
<Button 
  variant="ghost" 
  size="icon"
  onClick={() => setWebSearchEnabled(!webSearchEnabled)}
  className={webSearchEnabled ? '某种高亮样式' : ''}
>
  <Search className="w-4 h-4" />
</Button>

// 发送消息时，把 webSearchEnabled 传出去
onSend({ message, webSearchEnabled, ... });
```

**复制这个模式**，用于知识库开关。

在 AiInputBar 组件中，在 `webSearchEnabled` 状态附近，新增：

```typescript

```

## STEP 3：新增知识库开关按钮

在输入栏的工具按钮区域（Web 搜索按钮旁边），新增知识库按钮：

```typescript
// 图标用 BookOpen 或 Library（从 lucide-react 导入）
import { BookOpen } from 'lucide-react';

// 按钮 — 完全参照 Web 搜索按钮的写法
<Button
  variant="ghost"
  size="icon"
  onClick={() => setKnowledgeBaseEnabled(!knowledgeBaseEnabled)}
  className={knowledgeBaseEnabled ? '和 webSearch 高亮时一样的 className' : ''}
  title={knowledgeBaseEnabled ? '关闭知识库' : '开启知识库'}
>
  <BookOpen className="w-4 h-4" />
</Button>
```

**按钮位置**：放在 Web 搜索按钮的旁边（左边或右边都行，保持视觉平衡）。

**高亮样式**：和 Web 搜索按钮激活时完全一样的样式。可能是：

- 背景色变化（如 `bg-primary/10`）
- 图标颜色变化（如 `text-primary`）
- 边框变化
- 或者是某个自定义 CSS class

**直接复制 Web 搜索按钮的 className 逻辑就行。**

## STEP 7：互斥处理（可选但推荐）

知识库模式和代码上下文模式不应该同时开启（task-04 中设计的是 codeContext 优先）。

在前端可以加一个简单的互斥逻辑：

```typescript
// 开启知识库时自动关闭代码上下文
function toggleKnowledgeBase() {
  const newValue = !knowledgeBaseEnabled;
  setKnowledgeBaseEnabled(newValue);
  if (newValue && codeContextEnabled) {
    setCodeContextEnabled(false);
  }
}

// 开启代码上下文时自动关闭知识库
function toggleCodeContext() {
  const newValue = !codeContextEnabled;
  setCodeContextEnabled(newValue);
  if (newValue && knowledgeBaseEnabled) {
    setKnowledgeBaseEnabled(false);
  }
}
```

**但如果实现太复杂就先不做**——后端已经处理了优先级（codeContext > knowledgeBase），即使前端两个都开着也不会出问题，只是 KB 会被忽略。

-----

## STEP 8：KB 来源标注在消息气泡中显示（可选增强）

当 AI 基于知识库回答时，回答中会包含「📄 来源：文档名」的文本。这个会被 `AIMessageContent.tsx` 的 Markdown 渲染器正常显示，**不需要额外改动**。

但如果想让来源标注更醒目，可以在 `AiMessageBubble.tsx` 中对包含「📄 来源：」的行做特殊样式处理。**这是可选增强，不是必须的。**
