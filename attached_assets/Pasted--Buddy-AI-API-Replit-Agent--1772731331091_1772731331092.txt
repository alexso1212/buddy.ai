## 第一幕：老板张总注册

### T01: 注册新用户（老板）

```bash
BOSS_RESULT=$(curl -s -X POST "http://localhost:5000/api/auth/register" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "zhangzong@xinda.test",
    "password": "Test123456",
    "name": "张总"
  }')
echo "T01 注册结果: $BOSS_RESULT"
BOSS_TOKEN=$(echo $BOSS_RESULT | grep -o '"token":"[^"]*"' | cut -d'"' -f4)
echo "T01 Token: ${BOSS_TOKEN:0:20}..."
```

预期：返回 token 和 user 信息，role 应为 owner

### T02: 获取当前用户信息

```bash
BOSS_ME=$(curl -s "http://localhost:5000/api/auth/me" \
  -H "Authorization: Bearer $BOSS_TOKEN")

```

预期：返回 user 对象，包含 id、name、role(owner)、orgId
