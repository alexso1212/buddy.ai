### 5. Auto-Scroll with User Override

Critical behavior:

- **Default**: Chat scrolls to bottom as new tokens arrive
- **User scrolls up**: Auto-scroll STOPS immediately. Do not fight the user.
- **User scrolls back to bottom** (within 50px of bottom edge): Auto-scroll RESUMES
- **User sends new message**: Force scroll to bottom regardless

Implementation approach:

```typescript
const isAutoScrolling = useRef(true);

function isNearBottom(): boolean {
  const el = containerRef.current;
  if (!el) return true;
  return el.scrollHeight - el.scrollTop - el.clientHeight < 50;
}

// On scroll event
function handleScroll() {
  isAutoScrolling.current = isNearBottom();
}

// On each new token
function scrollToBottom() {
  if (!isAutoScrolling.current) return;
  containerRef.current?.scrollTo({ top: containerRef.current.scrollHeight, behavior: 'smooth' });
}
```

### 8. SSE AbortController Cleanup

CRITICAL: Every SSE request must use an AbortController. When the component unmounts OR the user stops generation OR a new message is sent, call `.abort()` on the controller. This prevents request leaks. This was a past bug — do not skip this.

```typescript
const abortRef = useRef<AbortController | null>(null);

function startStream() {
  abortRef.current?.abort(); // Kill any existing stream
  abortRef.current = new AbortController();
  fetch(url, { signal: abortRef.current.signal, ... });
}

function stopStream() {
  abortRef.current?.abort();
  // → trigger action buttons fade-in
  // → switch stop button back to send button
}

// On unmount
useEffect(() => {
  return () => abortRef.current?.abort();
}, []);
```
