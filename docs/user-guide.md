## 1. 登录与注册

Buddy 支持多种登录方式：

- **邮箱 + 密码**：输入注册邮箱和密码登录，密码至少 8 位
- **社交账号登录**：支持 Google、Apple、GitHub 一键登录（通过安全的 OIDC 协议）
- **Telegram 登录**：通过 Telegram Login Widget 一键授权登录

首次使用需要先注册账号，注册后会自动进入新用户引导流程。

> 如果你通过社交账号或 Telegram 登录且系统中不存在该账号，会自动为你创建新账号。

## 2. 新用户引导（Onboarding）

新用户注册后，如果尚未加入任何组织，系统会自动引导你完成以下步骤：

### 创建组织

1. 在欢迎页选择「创建组织」
2. 填写组织名称和类型
3. 系统会自动生成一个人类友好的邀请码（如 `DPE-X4NM`）
4. 将邀请码分享给同事，他们可以用它申请加入
5. 创建成功后，你会自动成为组织的 **Owner**

### 加入组织

1. 在欢迎页选择「加入组织」
2. 输入同事分享的邀请码
3. 查看组织信息（名称、类型、成员数、是否公开）
4. 提交加入申请，可附上一段自我介绍
5. 等待管理员审批 — 页面会自动轮询审批状态，通过后自动跳转到工作台

## 3. 仪表盘

仪表盘是登录后的首页，提供全局概览：

### 统计卡片

- **任务总数**、**进行中**、**已完成**、**已逾期**、**待审核** 五项关键指标
- **今日 / 本周 / 本月** 新增任务数量

### 需要关注

优先展示以下需要你注意的任务：

- 已逾期的任务
- 即将到期的任务
- 需要补充信息的任务（标记为「待补充」）

> 桌面端以表格形式展示，移动端使用可滑动的任务卡片。

## 4. AI 智能助手（Agent）

Agent 是 Buddy 的核心功能 — 一个深度集成任务管理的 AI 聊天助手。

### 基本聊天

- 在底部输入框中输入问题或指令，AI 会以流式方式即时回复
- 支持 Markdown 格式渲染，包括代码语法高亮（highlight.js）
- 每条 AI 回复显示 token 用量徽章
- 消息显示发送时间（HH:MM 格式）

### 对话管理

- **多对话**：左侧边栏可创建、切换和管理多个对话
- **搜索**：搜索历史对话
- **星标**：将重要对话标记为星标，方便快速查找
- **重命名 / 归档 / 删除**：右键或长按对话可进行管理
- **后台生成**：切换到其他对话时，AI 的回复会在后台继续生成并保存，侧边栏会显示脉冲动画指示正在生成的对话

### 消息操作

悬停在消息上可以看到操作按钮：

- **编辑消息**：点击铅笔图标编辑你发的消息并重新发送（后续消息会被截断）
- **重新生成**：对 AI 的回复不满意时，点击重试按钮
- **复制**：一键复制 AI 回复内容
- **超时检测**：如果 AI 响应超过 45 秒，会自动提示超时并提供重试按钮

### AI 思考过程

当 AI 使用扩展思维模式时，会显示一个可折叠的「思考过程」区域：

- 默认折叠，点击展开查看 AI 的完整推理步骤
- 显示思考时长和字符数（如「1,234 字」）
- 支持 Markdown 渲染和复制
- 历史消息中的思考过程默认折叠显示

### 智能操作

AI 可以直接帮你执行任务管理操作：

- **创建任务**：告诉 AI「创建一个任务：明天完成产品调研」，AI 会生成一张操作确认卡片
- **查询任务**：询问「我有哪些未完成的任务？」，AI 会查询数据并给出分析
- **修改任务**：「把那个任务的优先级改为高」，AI 生成修改确认卡
- **批量操作**：AI 可以一次提议多个操作，你可以逐个确认或一键全部确认
- **跳过操作**：对不需要的操作直接跳过
- **确认卡动画**：确认/跳过时有 spinner 加载动画

> 确认操作后，AI 会自动将操作结果注入到对话上下文中，后续交流无需重复说明。

### 交互式输入面板

当 AI 需要你从有限选项中选择时（如选择部门、设置优先级），会从底部弹出一个交互式选择面板：

- **单选（single_select）**：点击选项后自动跳转到下一题，最后一题点击后自动提交
- **多选（multi_select）**：可选择多个选项，选好后点击确认按钮
- **优先级排序（rank_priorities）**：拖拽选项上下调整排列顺序
- **分页导航**：多个问题时，顶部显示「< 1 of N >」页码导航
- **自定义输入**：单选和多选支持手动输入自定义答案
- **手势操作**：支持左右滑动切换问题
- **关闭方式**：点击半透明遮罩、X 按钮或按 Escape 键可关闭面板
- **键盘导航**：支持 Tab 在选项间切换，Enter / Space 选择

> 你的选择会以格式化文本发送到对话中（如「部门：技术部」），AI 会基于你的选择继续工作。

### 增强功能（输入栏 + 号菜单）

点击输入栏左下角的 **+** 按钮，可以开启以下增强功能：

| 功能 | 说明 |
|------|------|
| **联网搜索** | AI 实时搜索互联网获取最新信息（通过 Tavily），搜索来源会显示在回复中 |
| **代码上下文** | AI 能自主阅读项目代码文件，回答关于代码结构和实现的问题 |
| **深度研究** | 对复杂问题进行更深入的分析 |

#### 代码上下文模式

开启「代码上下文」后：

- 输入栏旁会出现蓝色「代码」徽章
- 顶部显示「已加载 X 个代码文件」信息栏
- AI 会自动读取项目文件来回答你的问题
- 在回复过程中，会看到灰色状态提示（如「正在读取 server/routes.ts...」「正在搜索 orgId...」），表示 AI 正在浏览代码
- AI 最多可执行 8 轮工具调用，包括读取文件、列出目录、搜索代码

### 回复风格

通过 + 号菜单可以选择 AI 的回复风格：

- 正常 / 简洁 / 详细 / 专业 / 休闲

### 文件附件

- 支持粘贴图片（Ctrl+V）或拖拽文件到输入框
- 支持的格式：图片、PDF、TXT、CSV、JSON、Markdown、Office 文档
- 移动端可直接调用摄像头拍照

### 长文档面板（Artifact）

当 AI 生成较长的文档（超过 2000 字符）或大段代码（超过 30 行）时，会出现「在面板中打开」按钮：

- 点击后在右侧滑出独立面板
- 支持全屏查看
- 可一键复制或下载为 `.md` 文件
- 支持 Markdown 渲染

### 智能建议

AI 会根据你的任务数据，在输入框上方显示智能建议卡片（如「分析团队负载」「查看待办任务」），点击即可快速提问。

### Token 余额提醒

当组织的 AI 使用量超过预算的 80% 时，Agent 页面会自动弹出低余额 toast 提醒。

## 5. 企业知识图谱（Graph）

图谱视图以力导向图的形式，可视化展示项目、任务和它们之间的依赖关系。

### 功能特点

- **节点和连线**：每个任务和项目是一个节点，依赖关系用连线表示
- **交互操作**：拖拽、缩放、点击节点查看详情
- **血管流动动画**：独特的动态效果展示数据和依赖的流向
- **协作健康度**：通过颜色编码直观展示项目和团队的健康状态
- **视图切换**：按部门或项目分组查看，可隐藏已完成/非活跃节点

### 图谱内 AI 聊天

点击图谱页面的聊天按钮，可以打开一个浮动聊天面板：

- 支持对当前图谱截图，发送给 AI 进行视觉分析
- 拥有与主 Agent 页面完全一致的聊天功能（包括交互式输入面板、思考过程、代码工具等）
- 可以边看图谱边和 AI 讨论项目结构
- 支持滚动到底部按钮和停止生成按钮

## 7. 任务管理

### 任务列表

- **多种筛选**：按项目、状态、负责人筛选
- **排序方式**：按截止日期、优先级、创建时间排序
- **需要审核标记**：带有「需要审核」标记的任务会特别展示
- **移动端优化**：支持左右滑动快捷操作

### 任务状态流转

每个任务按以下状态流转：

```
待办(todo) → 进行中(in_progress) → 已提交(submitted) → 审核中(reviewing) → 已完成(done)
                                                                           ↘ 已取消(cancelled)
```

### 任务优先级

从高到低：**紧急(critical)** → **高(high)** → **中(medium)** → **低(low)**

### 任务详情

- 查看和编辑任务的标题、描述、优先级、截止日期等
- 管理任务参与者
- 查看任务评论和活动日志
- 查看 AI 评审结果和判定
- AI 标注的警告信息（如推测的截止日期、待确认的负责人）

### 任务交付物

任务支持添加交付物，用于记录工作成果：

| 类型 | 说明 |
|------|------|
| **文件** | 上传工作文档、设计稿等文件 |
| **链接** | 粘贴外部链接（如 Figma、Google Docs） |
| **文本** | 直接撰写文本内容（支持 Markdown） |
| **AI 生成** | 由 AI 自动生成的内容 |

交付物支持版本管理，重新提交时会自动标记旧版本。

### 提交审核

完成交付物后，可以提交审核：

1. 选择要提交的交付物
2. 填写提交说明
3. 提交后任务状态变为「已提交」
4. 管理员（Owner / Admin / Head）进行审核评分

## 8. 团队管理

团队页面包含以下 Tab：

### 成员（所有人可见）

- 查看组织内所有成员列表
- 显示每个成员的角色、部门和职位
- 管理员可以调整成员角色

### 部门（所有人可见）

- 查看和管理组织的部门结构
- 支持嵌套的部门树状视图

### 职位（所有人可见）

- 定义和管理组织内的职位/岗位

### 加入申请（仅 Owner / Admin 可见）

- 查看待审批的加入申请列表
- 每条申请显示申请人信息、留言和申请时间
- 可以批准或拒绝申请（拒绝时可在弹窗中填写原因）
- 底部可展开查看已处理的历史记录
- 待审批数量会以红色徽章显示在 Tab 标题上

### 邀请码（仅 Owner / Admin 可见）

- 查看当前组织的邀请码
- 一键复制邀请码
- 组织 Owner 可以重新生成邀请码（需二次确认，旧邀请码立即失效）

## 9. 设置

### Token 预算管理

- 查看组织的 AI 使用量（已用金额 / 总预算）
- 进度条用颜色提示用量状态：
  - 🟢 绿色：用量正常
  - 🟠 橙色：接近上限
  - 🔴 红色：即将用完
- 管理员可设置每月 token 预算和计费周期重置日
- 当月使用量超过 80% 时，Agent 页面会显示低余额提醒

### 主题设置

- 支持浅色 / 深色 / 跟随系统三种主题模式

### 个人信息

- 查看和编辑个人资料

## 12. 移动端适配

Buddy 针对移动设备做了专门优化：

- 响应式布局，适配各种屏幕尺寸
- 任务卡片支持左右滑动快捷操作
- 输入框自动适配虚拟键盘，不会被键盘遮挡
- 图谱聊天面板适配键盘弹出场景，使用 Portal 渲染避免容器裁剪
- 交互式输入面板支持触控拖拽排序和滑动切换
- 统计数据在小屏幕上使用紧凑布局
- 底部安全区域适配（iPhone 等设备的 Home 指示条区域）
